# 글에서 사용하는 이미지

이 폴더에는 공개할 PNG·JPEG·WebP·GIF·AVIF 파일만 넣습니다. 글에는 다음처럼 입력합니다.

```markdown
![요청과 응답을 확인한 화면](/media/request-response.webp)
```

한 파일은 10MB 이하여야 합니다. 게시된 글에서 참조한 이미지만 사이트 빌드 결과에 복사하며 잘못된 경로나 없는 파일은 빌드에서 알려줍니다. 공개 GitHub 저장소에 넣은 원본 파일은 글의 게시 여부와 관계없이 공개됩니다. 토큰·쿠키·계정 정보가 들어 있는 캡처는 올리기 전에 가려 주세요.

기존 Sites 편집기는 이미지 주소 입력을 지원합니다. 이 폴더는 GitHub Pages용 공개 이미지 관리이며, Sites에 파일을 직접 업로드하는 기능은 아닙니다.
