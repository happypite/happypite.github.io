공개 보고서는 Claude Code 2.1.322에서 Fable 5.2, Fable 5.1, Opus 5.5를 같은 설정으로 비교했다. Terminal-Bench 2.1의 과제 52개를 모델마다 두 번씩 실행해 총 312번 시도했고, 답변을 다른 AI가 평가하는 대신 각 과제의 테스트로 채점했다.

해결률은 Fable 5.2가 82.7%, Opus 5.5가 84.6%였다. 숫자만 보면 Opus가 1.9%포인트 높지만, 보고서는 이 실험에서 해결률 차이가 뚜렷하게 확인되지는 않았다고 해석했다. 그렇다고 두 모델의 성능이 모든 작업에서 같다는 뜻은 아니다. 두 모델 모두 잘 푸는 과제가 많아 차이를 가리려면 더 어려운 과제가 필요하다는 한계도 적었다.

비용 차이는 더 분명했다. 성공한 작업당 비용은 Fable 5.2가 1.83달러, Opus 5.5가 0.65달러로 약 2.8배 차이 났다. 이 값은 실험에서 API 호출별로 측정한 정가 기준 비용이며, 월 구독료나 모든 사용자의 실제 지출을 비교한 값은 아니다.

## 내 작업에 적용할 때 확인할 것

이번 결과에서 참고할 부분은 어느 모델이 무조건 낫다는 결론보다 비교 방식이다. 같은 과제와 실행 환경을 두고, 해결률뿐 아니라 비용과 걸린 시간까지 함께 기록했다.

개발에 AI를 쓴다면 내가 반복해서 하는 작업 몇 가지로 작은 비교부터 해볼 수 있겠다. 오류 수정, 테스트 작성, 코드 설명처럼 작업을 나누고 결과가 맞는지 확인할 기준을 먼저 정해 두는 것이다. 한 번 잘 풀었다는 인상보다 반복했을 때 얼마나 일관되게 해결하는지가 더 도움이 될 것 같다.

모델만 같으면 실행 도구의 버전은 상관없다고 생각하기 쉽지만, 보고서는 Claude Code가 모델을 제대로 인식하는지와 대화가 중간에 요약되는지도 확인했다. 다만 도구 버전 변경이 성능 변화를 일으켰다고 단정하지는 않았다.

새 모델이 나올 때마다 바로 기본 모델을 바꾸기보다는, 내 작업에서 성공한 결과 하나를 얻는 데 드는 비용과 검토 시간을 같이 확인해봐야겠다. 공개된 52개 과제의 결과를 내 프로젝트나 보안 진단 성능으로 그대로 옮겨 받아들이지 않는 것도 필요하다.
